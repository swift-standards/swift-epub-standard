# swift-epub-standard

Use this package when you work with EPUB 3.3 publications and want the Institute's standard import rather than a dependency on a specific specification package. It adds nothing of its own: importing it imports `W3C_EPUB` from swift-w3c-epub, so start from `W3C_EPUB`. If you want to depend on the W3C implementation directly, use swift-w3c-epub.
